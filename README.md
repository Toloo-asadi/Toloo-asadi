# Toloo Asadi

MSc Digital Humanities student at the University of Genoa (expected March 2027),
looking for entry-level roles in machine learning and computer vision.

I build Python pipelines that turn video and motion data into signals models can
learn from. My master's thesis, with researchers at the University of Genoa and IIT,
asks whether machine learning can tell four vitality forms (enthusiastic, fed up,
gentle, rude) apart in human movement. It is in progress, and the data is not public.

## What I work with
- Python, pandas, PyTorch, scikit-learn
- OpenCV, facial landmarks, Action Units, time-series analysis
